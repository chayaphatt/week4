## About This Assignment

เป็นการพัฒนาต่อยอดและรีดีไซน์หน้าเว็บไซต์สูตรอาหาร (Recipe Website - The Pizza Dip & Pull-Apart Bread) ให้มีความพรีเมียม ทันสมัย และดึงดูดผู้เข้าชมมากยิ่งขึ้น โดยมุ่งเน้นการฝึกปฏิบัติเกี่ยวกับ:
* การจัดวางเลย์เอาต์ขั้นสูงด้วย CSS Grid และ Flexbox
* การปรับแต่งโทนสี และการจับคู่สีของการ์ดเนื้อหาย่อยให้มีความกลมกลืน ละมุน และดูเป็นระเบียบเรียบร้อย
* การจัดการและปรับแต่งรูปภาพประกอบทั้งหมด Ingredients และ Steps ให้แสดงผลเต็มส่วนอย่างพอดีโดยไม่ถูกครอปตัดขอบในทุกมุมมอง
* การออกแบบระบบ Responsive Web Design ที่รองรับการแสดงผลได้อย่างราบรื่นในทุกอุปกรณ์

## Results & Responsive Design 

เว็บไซต์ได้รับการออกแบบและพัฒนาด้วยหลักการ Responsive Design โดยแบ่งการแสดงผลตามขนาดหน้าจอออกเป็น 3 ระดับหลัก:

* **หน้าจอขนาดใหญ่ / Desktop (ความกว้างตั้งแต่ 1024px ขึ้นไป):** 
  * เลย์เอาต์แสดงผลเต็มรูปแบบ จัดวางส่วนประกอบและสัดส่วนคอลัมน์อย่างสมดุล
  * รูปภาพวัตถุดิบและขั้นตอนการทำได้รับการปรับแต่งขนาดด้วย `object-fit: contain` ให้แสดงผลเต็มพื้นที่อย่างพอดี ไม่ถูกตัดขอบหรือซูมจนล้น มองเห็นรายละเอียดทั้งหมดได้ครบถ้วนชัดเจน
* **หน้าจอขนาดกลาง / Tablet (ความกว้างตั้งแต่ 768px ถึง 1023px):** 
  * ระบบจะปรับเปลี่ยนการจัดวางเป็นระบบคอลัมน์คู่ (2 Columns) สำหรับส่วนวัตถุดิบและภาพประกอบ เพื่อความกระชับและอ่านง่าย
* **หน้าจอขนาดเล็ก / Mobile (ความกว้างต่ำกว่า 768px ลงมา):** 
  * องค์ประกอบทั้งหมดจะถูกปรับเปลี่ยนเป็นการเรียงตัวในแนวตั้งแบบ 1 คอลัมน์ (Stack) อย่างเป็นระเบียบ เลื่อนอ่านง่าย และใช้งานบนมือถือได้อย่างลื่นไหลโดยไม่มีอาการเนื้อหาล้นจอ
